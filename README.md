# fahsai-mcp-server

An [MCP](https://modelcontextprotocol.io) server exposing [Fahsai](https://fahsai.fyi)'s public data — active fire detections, PM2.5 air quality, weather/wind, and power plants across Thailand, Myanmar, Laos, and Cambodia — as LLM-friendly tools.

See [`CLAUDE.md`](CLAUDE.md) and [`docs/claude/`](docs/claude/) for architecture and conventions.
